# PsicoCitas
Aplicación para la gestión de citas de una clínica psicológica. Permite a los pacientes reservar y administrar sus citas, a los psicólogos gestionar su agenda y disponibilidad, y a los administradores supervisar la operación.

## Roles de usuario 

- Paciente: Registrarse, consultar disponibilidad, reservar, reprogramar y cancelar citas.
- Psicólogo: Ver sus citas y agenda, definir y bloquear horarios.
- Administrador: Gestionar usuarios, psicólogos, horarios, citas y permisos.

|      Rol      | Qué puede hacer                                                               |
|:-------------:| ----------------------------------------------------------------------------- |
|   Paciente    | Registrarse, consultar disponibilidad, reservar, reprogramar y cancelar citas |
|   Psicólogo   | Ver sus citas y agenda, definir y bloquear horarios                           |
| Administrador | Gestionar usuarios, psicólogos, horarios, citas y permisos                    |


## Stack Tecnológico

|        Capa         | Tecnologías                                                                               |
|:-------------------:| ----------------------------------------------------------------------------------------- |
|     **Backend**     | Java, Spring Boot (Spring MVC, Spring Security)                                           |
|    **Frontend**     | Thymeleaf, HTML5, CSS3, Bootstrap, JavaScript                                             |
|  **Persistencia**   | Hibernate/JPA, MySQL                                                                      |
| **Infraestructura** | Render.com (despliegue), Firebase Storage (archivos), Git y GitHub (control de versiones) |
